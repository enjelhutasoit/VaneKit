# ADR-0001: Clean-room rule and naming

## Decision
- All names, token values and public APIs are designed from scratch for VaneKit.
- Sources are limited to public specifications and guidelines (Apple HIG, WCAG).
- Work is committed incrementally so the history shows how decisions evolved.

## Consequences
- Clean-room status is process-based and cannot be proven by code alone.
- Token values are a deliberate, documented choice, not a reproduction of any
  other system.
