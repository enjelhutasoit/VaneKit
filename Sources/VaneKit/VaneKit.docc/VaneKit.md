# ``VaneKit``

A clean-room SwiftUI design system: semantic tokens and accessible components.

## Overview

VaneKit provides color roles with light and dark palettes, a spacing scale,
typography based on system text styles, and a small set of components.
Component text is always supplied by the caller, already localized.

VaneKit is original work built from public sources only. See the repository
README for the clean-room statement.
